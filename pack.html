Seals a display address and pre-shared key into deploy-config.js. Drop that file next to index.html and the console starts locked: it asks for the password below instead of asking each person for the address and the key.

Everything happens in this page. Nothing is uploaded, and nothing is written anywhere until you save the file yourself.

Leave blank if the deployed page will be served by the bundled proxy, which answers on its own origin.

A starting value. Each browser can change it afterwards, and remembers its own.

Anyone who can load the page can also take a copy of the sealed file and guess at it offline, so pick a password worth guessing at. There is no way to recover the contents if it is forgotten; repack instead.
